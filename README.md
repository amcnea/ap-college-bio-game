# AP College Bio Game

Godot 4 game that teaches AP Biology by making course principles the rules of play. Android first.

Unit 1 first slice: water lattice + methanol (hydroxyl sticks, methyl does not).

## Play

Drag methanol. Tap it to face/rotate. Hydroxyl (OH) forms hydrogen bonds with water. Methyl (CH3) is a dead face — no stick, a cohesion tax, not an eject. Hold a shape (keep OH stuck) to win.

## Run on a computer

1. Install Godot 4.2+ (Standard, not .NET) from https://godotengine.org/download
2. Clone or download this repo.
3. In Godot: Import, pick the folder that contains `project.godot`, then press Play (F5).

Android export: Editor → Export → Add Android. Needs Android SDK / command-line tools. Debug APK is enough to sideload.
